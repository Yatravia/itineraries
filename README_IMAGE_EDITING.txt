YATRAVIA ITINERARY – EDIT IMAGE LINKS

1. Keep the HTML file and images/ folder together.
2. Open HTML in VS Code or a text editor.
3. Ctrl+F: DAY 3 IMAGES START (replace 3 with any day number).
4. Edit only the URL between src="..." of the desired image.
5. To add an image, duplicate an entire <div class="photo"> ... </div> image block before the DAY N IMAGES END comment.
6. To remove an image, delete that entire <div class="photo"> ... </div> block.
7. Save; no JavaScript edits are needed.

The images are linked from external references; internet access is needed to display them.
The Yatravia logo is stored in images/yatravia-logo.png.
